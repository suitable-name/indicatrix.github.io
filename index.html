Indicatrix

Spectral path tracer and faceting-design CAD for cut gemstones

Download for Windows or Linux Read the user manual

Indicatrix is a spectral path tracer for cut gemstones. It traces light through the stone with hero-wavelength sampling, polarization and birefringence, and evaluates the refractive index per wavelength from Sellmeier and Cauchy data instead of a fixed RGB approximation. The physics runs on the CPU and, optionally, as a GPU kernel that is checked against the CPU reference.

Use it to preview faceting designs before cutting, to compare how different gem materials render the same cut, and to produce reference-quality still renders. Designs come from GemCAD-style .asc cutting instructions or from Indicatrix's own faceting editor.

Status: the renderer is usable today. The faceting CAD and the rough planner are beta and under active development (see the faceting CAD section). Indicatrix is MIT licensed.

3What is modelled and how it is checked

Each ray carries eight wavelengths at once (one hero wavelength and seven companions), a Stokes vector that is rotated through a Mueller matrix at every facet, and a dispersion curve per material. Uniaxial and biaxial crystals split into ordinary and extraordinary rays, pleochroic stones absorb differently along each direction, and the stone itself is a set of planes (plus subtracted tools for concave facets), not a triangle mesh. The result is integrated against the CIE 1931 colour-matching functions and tone mapped.

The GPU kernel is a hand-written port, so it is verified in tiers against the CPU: bit-exact random state, per-function ULP budgets, statistical comparison of whole images, and a white-furnace test against an analytic answer.

4The studio

indicatrix-cut is the desktop application: a design library on the left and a live 3D viewport on the right. The library is a local database with no account, searchable by shape, index gear, facet count and length/width ratio, and it can also browse a remote coordinator's catalogue. The viewport shows either a fast solid preview or the full spectral path tracer, with lighting presets from a light tent to a grading tray and daylight, custom HDR environments, live brilliance, windowing and extinction readouts, and tilt sweeps that show how a design behaves in the hand and not only face-up. Stills export up to 8192 × 8192 pixels, and a queue renders stills and tilt videos overnight.

One Simple / Advanced switch hides or shows controls without touching any design. The user manual is built into the program (Help → User Manual, or F1 for the page about whatever is on screen), and Ctrl+K opens a command palette that reaches most actions by name.

5Faceting CAD (beta)

STATUS

The faceting CAD is in beta. Its interaction model is still evolving and the newest parts have had less hands-on use, so check a design against an established CAD before you cut from it. Indicatrix is meant to grow into a complete faceting suite.

The editor treats the cutting instructions as a constraint graph, not a list of numbers. A solver resolves every facet's cutting depth from its meet constraints, a tier's angle can follow other tiers through a relation such as =P1 - 2, and concave facets cut with a cylinder, cone, circle, disc or sphere tool are part of the design. Optimizer, Retarget for another material, angle sweeps, history and variants, a step-by-step cutting mode for the bench and 68 short tutorials are built around it. The printable cutting sheet lists the facets in cutting order with positive angles, and a design can be exchanged as GemCAD .asc, Indicatrix's own .indicatrix, and .gem or .gcs files from GemCAD and Gem Cut Studio.

The beta Rough planner (Library → Plan Rough...) takes a block, cylinder, pebble or scanned mesh of rough and ranks up to 10 ways of cutting up to 99 stones from the designs in your library. The same engines run without a window in indicatrix-cli.

6Materials

32 built-in gem materials, each with a dispersion fit either taken from the optics literature or derived from corroborating gemological references. You can add your own, with Sellmeier or Cauchy coefficients that are validated before use, and give any stone a custom colour by tone, saturation and hue. The same list is offered by the renderer and the CAD editor.

7Distributed rendering

The viewport renders locally while the camera moves, then hands sample tracing to a coordinator once it settles. Work is split by sample-index range, not by screen tile, so a stone's few expensive facets do not unbalance the machines. The coordinator can trace itself and also drives render workers that dial out to it, so machines behind NAT or in the cloud can join, and a worker that drops out mid-job loses nothing. Local and remote samples are summed, never duplicated; results travel losslessly compressed, or as a finished picture when bandwidth matters more. Every connection is mutual TLS 1.3 with one-time token enrolment.

8Downloads

Indicatrix comes as ready-built programs for Windows and Linux. To start straight away, take one of the builds below. They are the scalar builds: made for the x86-64-v2 level, they run on any 64-bit Intel or AMD processor with SSE4.2, so there is nothing to choose. The GPU builds add the GPU path tracer; the CPU builds render on the processor only.

9Getting started

Nothing to install: the browser version is at live.indicatrix-suite.com (see the web app page for what it can do). For the design library, the GPU and remote rendering, download the desktop application from the downloads section, or install it with Cargo.

terminal — install from crates.io
cargo install indicatrix-cut --features gpu
indicatrix-cut

Then open a design from the library, pick a material and a lighting, and the live render starts. A first render takes a few clicks and no settings. The user manual explains every window step by step, and it is also built into the program under Help → User Manual.

12Status and limitations

  • The faceting CAD is beta and its interaction model is still changing: check a design against an established CAD before you cut it.
  • The browser build renders on the CPU, keeps a design only for the life of the tab, and has no design library, remote rendering, Deep Solve, tutorials, cutting mode or concave tools.
  • The GPU path needs a wgpu adapter with enough storage buffers; otherwise rendering falls back to the CPU.
  • Concave stones, and scenes lit by a UV lamp preset, are always traced on the CPU, so they render slower.
  • For concave tiers the optimizer and the angle sweep score the flat stone.
  • The Rough planner reads OBJ, STL and PLY meshes up to 64 MiB, repairs small defects, and falls back to a convex outline for very heavy, open or self-crossing meshes; a smooth scan that is too heavy is refused.
  • Inclusions are not yet available on block, cylinder or pebble roughs.
  • The command-line tool takes one design file per command, and its .gcs export is experimental.
